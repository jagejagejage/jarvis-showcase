# Jarvis Development

Jarvis is an ongoing personal AI assistant project that I continuously develop and improve.

This document tracks major milestones in the project's development rather than every individual code change.

## Project Beginning

Jarvis started as an experiment in building a personal AI assistant and learning how artificial intelligence could be integrated into useful software.

The project has grown significantly since its original version as I have continued experimenting, testing ideas, fixing problems, and adding new capabilities.

## Development Approach

Jarvis is built using an AI-assisted development workflow.

I direct the development of the project by deciding what I want Jarvis to do, designing features and workflows, testing implementations, identifying problems, and iterating on the system.

AI development tools assist with tasks such as generating code, debugging issues, implementing changes, and exploring possible solutions.

## Major Milestones

### Initial Development

- Created the original Jarvis project.

### Expansion

- Expanded Jarvis beyond its original capabilities.
- Added additional tools and integrations.

### Current Development

Jarvis is currently undergoing active development.

The current development cycle is focused on improving its capabilities, reliability, integrations, and overall usefulness.

Because development is ongoing, this showcase documents major stable milestones rather than every individual change.
